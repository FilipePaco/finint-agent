# Agent evaluation

Generated by `make eval-report` from `eval/results/*.jsonl`. Eval set: 76 alerts from the test period (`eval/eval_set.jsonl`): natural alerts raised by the champion model (laundering stratified by typology, plus false positives) and forced alerts carrying injected test cases (prompt injection, sanctions near-matches, adverse media). ## Limitations

- Ground truth is the synthetic dataset's label for the account-day; an alert counts as laundering if any transaction that day is labelled laundering.
- The simulated analyst follows the label; real analyst disagreement is not modelled.
- Free-tier rate limits make runs slower; costs are list-price estimates, not invoices.
- LLM outputs vary between runs; the record/replay CI job checks the pipeline, not the model's quality.
